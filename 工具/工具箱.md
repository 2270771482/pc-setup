# 工具箱（复用库索引）

入库门槛：**同一件东西用到第二次才收进来**；一次性的不进库。
每个条目一行：叫什么 / 什么时候用得上 / 在哪。三个月没用到的降级或删掉。

## 能直接跑的

| 名字 | 什么时候用得上 | 位置 |
|---|---|---|
| 启动数据库 | 要用 MySQL / PostgreSQL（平时是手动启动状态） | `工具\启动数据库.cmd` |
| 发布私有仓 | 改过 `状态.md` / `决策记录\` / `任务\` 之后，同步到 GitHub 私有仓 | `脚本\发布私有仓.py` |
| 重建 Codex 工作目录联接 | 重装系统后，让 `C:\Users\22707\Documents\Codex` 重新指向 `D:\Codex` | `脚本\重建Codex工作目录联接.ps1` |
| 体检 | 收工前 / 每周一次：查文件行数、任务清单、git、备份、磁盘 | `工具\体检.cmd` |
| 恢复「文档/下载」重定向 | 重装系统后，或 OneDrive 把文档抢回 C 盘时 | `脚本\restore-known-folders.ps1` |
| Docker 数据目录迁到 D 盘 | Docker 启动失败（socket 僵死）或需要重建 Docker 环境时 | `脚本\docker-relocate-to-d.ps1` |
| 两个数据库改手动启动 | 重装后想恢复「平时不跑」的状态 | `脚本\set-databases-manual.ps1` |
| 批量装软件的骨架 | 重装系统时参考它改一份新的 | `脚本\install-all.ps1` |
| 量开机耗时 | 想知道真实开机秒数、核对开机优化效果（**要右键以管理员身份运行**） | `工具\量开机耗时.cmd` |

一次性脚本（装机当天用过、装完就没用了）都躺在 `脚本\archive\`，留作查证用，不再维护。

## 套路与约定

| 名字 | 什么时候用得上 | 位置 |
|---|---|---|
| 主管理约定（红线、开工流程、公私有规则） | 每次开工必读 | `AGENTS.md` |
| 项目索引 | 新建项目、想知道有哪些项目时 | `项目登记表.md` |
| 未完成事项 | 每次开工先看 | `任务清单.md` |
| 经验教训（知识库，按主题分册） | 遇到「这个坑好像踩过」「这东西怎么弄」时 | `知识库\` |
| 真决策（按月） | 想知道某件事为什么这么定、要推翻旧结论时 | `决策记录\<年-月>.md` |
