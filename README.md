# 主管理（D:\AI）

这里管这台电脑的公共部分：装机与维护规则、现状记录、经验教训。具体项目放 `D:\Projects\<名字>`。

新会话从本目录开始时，先读：

1. `AGENTS.md`：工作规则与权限边界
2. `任务.md`：要做什么（既是总览也是事实源）
3. `状态.md`：本机当前是什么样

主要目录与文件：

- `任务.md`：待办，直接改这一个文件
- `状态.md`：现状（机器、硬盘、软件、目录与数据）
- `决策记录\`：为什么这样定，只追加；`决策记录.md` 是索引
- `知识库\`：验证过的做法与排查经验
- `文档\`：给人看的说明，索引见 `文档\README.md`（核心是 `重装清单.md`）；`文档\archive\` 是过期文档
- `安装规划.md`：什么软件装到哪
- `项目登记表.md`：有哪些项目
- `脚本\`：脚本源码；一次性脚本归 `脚本\archive\`
- `工具\`：可直接双击的入口，索引见 `工具\工具箱.md`
- `产物\`：临时产物，**用完即弃**
- `收件箱\`：暂时归不了类的东西

## 换电脑 / 新机器怎么复现这套环境

**顺序不能反**：先能上网，再装其余。

1. 装 **Codex**（微软商店，国内直连可用）和 **Clash Verge** → 导入订阅、开系统代理
2. 拉仓库：公开仓 `2270771482/pc-setup`（装什么、装到哪、知识与脚本）；
   私有仓 `2270771482/pc-setup-private`（`状态.md` 现状、`决策记录\`、`任务.md`、`重装清单.md`）
3. 按 **`文档\重装清单.md`** 决定「装什么、从哪下、密钥从哪取」（密钥只在 KeePassXC 里，不在仓库）
4. 按 **`安装规划.md`** 决定「装到哪、数据目录指哪」，装完一个就在 `状态.md` 记一行
5. 顺序、坑、静默参数看 **`知识库\`**；`AGENTS.md` 是给会话看的规则

> 更彻底的方案（一个包自动跑完）见 `任务.md` 里的 **T-20260919-01 重装引导子项目**，目前挂起。

## 仓库

- **公开仓 `pc-setup`**（origin）：放能公开的部分——`AGENTS.md`、`README.md`、`安装规划.md`、
  项目登记表、`脚本\`、`工具\`、`知识库\`、`文档\`（`重装清单.md` 与 `archive\` 除外，见 `.gitignore` 白名单）
- **私有仓 `pc-setup-private`**：`状态.md`、`决策记录\`、`任务.md`、`文档\重装清单.md` 的快照；
  同步跑 `python D:\AI\脚本\发布私有仓.py`
- **密钥、令牌、账号密码一律不进任何仓库**，值放 KeePassXC（`D:\Documents\密码.kdbx`）
