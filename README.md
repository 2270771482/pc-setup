# D:\AI

这个工作区（也是 Obsidian vault）装下所有**文字**：

- **公开**：知识、文档、脚本、工具 —— 进公开仓 `pc-setup`（由 `.gitignore` 白名单决定）
- **本地**：`私人\`（简历/面试）、`_收件箱\`、`归档\` —— 只在本机，不进任何仓库
- **私密**：`private\`（状态/任务/决策/凭据）—— 是嵌套的**独立 git 仓**，推 `pc-setup-private`

**项目不在里面**，在 `D:\Projects`（各有自己的仓）。

## 我要做什么 → 读哪个

| 我想… | 去哪 |
|---|---|
| 查某件事怎么做（装软件 / 配网络 / PowerShell 写法） | `知识库\` |
| 看当初为什么这么定 | `private\决策记录\` |
| 找现成的脚本 | `脚本\` |
| 找个能双击的小工具 | `工具\` |
| 看规则和流程怎么走 | `知识库\治理体系.md`（唯一权威） |
| 找具体项目 | `D:\Projects\` |
| 找简历 / 面试 / 能力资料 | `私人\` |
| 看机器现状 / 待办 / 凭据指路 | `private\` |
| 临时扔个东西 | `_收件箱\`（每周清空） |
| 翻旧文件 | `归档\` |

## 知识库

| 主题 | 覆盖什么 |
|---|---|
| `系统与网络.md` | Windows 账户与权限、文件与磁盘、开机与服务、网络与代理 |
| `软件.md` | 软件安装与卸载、Docker |
| `硬件.md` | 硬件与磁盘健康 |
| `AI工具.md` | Codex CLI、飞书应用与机器人 |
| `PowerShell.md` | 编码坑、中文路径、脚本习惯 |
| `治理体系.md` | 规则怎么落地（含目录职责表） |

## 三条约定

1. **会过期的归管理，不会过期的归记忆** —— 现状/任务/决策是管理，做法与坑是记忆
2. **同一个事实只写一处** —— 发现写了两处，删一份，别两边同步
3. **临时文件先落 `_收件箱\`**，每周清空；不做这步，目录就会重新长乱

## 仓库

- 公开仓 `pc-setup` ← 本目录，`.gitignore` 是**按目录名放行**的白名单。
  ⚠️ **改名 `知识库\`、`文档\`、`脚本\`、`工具\` 之前必须先改 `.gitignore`**，否则会静默漏文件。
- 私密仓 `pc-setup-private` ← `D:\AI\private`，同步用 `python 脚本\发布私有仓.py`
