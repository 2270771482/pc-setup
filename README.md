# 主管理（D:\AI）

这里管这台电脑的公共部分：装机与维护规则、现状记录、经验教训。具体项目放 `D:\Projects\<名字>`。

新会话从本目录开始时，先读：

1. `AGENTS.md`：工作规则与权限边界
2. `任务.md`：要做什么（既是总览也是事实源）
3. `状态.md`：本机当前是什么样

主要目录与文件：

- `任务.md`：待办，直接改这一个文件
- `状态.md`：现状（机器、硬盘、软件、目录与数据）
- `决策记录\`：为什么这样定，只追加；`决策记录.md` 是索引
- `知识库\`：验证过的做法与排查经验
- `文档\`：给人看的说明（含 `重装清单.md`、备忘录）；`文档\archive\` 是过期文档
- `安装规划.md`：什么软件装到哪
- `项目登记表.md`：有哪些项目
- `脚本\`：脚本源码；一次性脚本归 `脚本\archive\`
- `工具\`：可直接双击的入口，索引见 `工具\工具箱.md`
- `产物\`：临时产物，**用完即弃**
- `收件箱\`：暂时归不了类的东西

**只在本机**：靠私有仓 `pc-setup-private` 给 `状态.md`、`决策记录\`、`任务.md` 做快照
