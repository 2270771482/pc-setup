# pc-setup：一台 Windows 电脑的装机与维护记录

> 这是 **Dell G15 5511（Windows 11 家庭版）这台机器**的管理仓库：装机清单、安装位置规划、
> 踩过的坑，以及给 AI 会话看的工作约定。
>
> 它解决的问题很具体：**换电脑或重装系统时，怎么不用凭记忆就把环境重现出来**；
> 以及**多个 AI 会话同时在这台机器上干活时，怎么不互相踩**。

## 这是什么

一台个人电脑的"说明书 + 施工记录"，四类内容分开放：

| 想知道 | 看哪 |
|---|---|
| 装什么、按什么顺序、每个模块怎么装 | `文档\软件与模块.md` |
| 装到哪、数据放哪 | `安装规划.md` |
| 这台机器现在什么样（硬件、磁盘、软件、数据目录） | `状态.md`（在私有仓） |
| 某个坑怎么躲、某件事怎么做 | `知识库\`（一个主题一个文件） |
| 为什么当初这么定 | `决策记录\`（只追加，不改旧条目） |
| AI 会话在这台机器上要守什么规矩 | `AGENTS.md` |

## 为什么要做成仓库

- **重装系统只清 C 盘**，所以任何不能丢的东西都放 D 盘；关键文件另外有离机副本（私有仓）
- **换新电脑/公司电脑**时，`git clone` 下来就能照着装，不用回忆上次是怎么弄的
- 会话会开新的、上下文会丢，所以**状态一律以文件为准，不依赖对话记忆**

## 如果你也想搭一套

1. 先看 `文档\软件与模块.md`——它是这份记录里最通用的一篇（模块划分 + 可粘贴的安装命令）
2. 再看 `安装规划.md`——怎么决定"程序放 C 盘、数据放 D 盘"
3. 把 `AGENTS.md` 抄一份改成你自己的规则，再建一个 `状态.md` 记现状，放进自己的 git 仓库
4. `知识库\` 里的踩坑记录可以直接翻（UAC 提权、PowerShell 编码、Docker 搬目录、开机优化…）

> ⚠️ 这里的清单是**针对这台 Dell G15 5511 和本人使用习惯**写的：盘符、目录、软件取舍都是。
> 换机器照抄之前，先比对 `状态.md` 的现状跟你的是否一致。

## 边界

- **密钥、令牌、账号密码不进这个仓库**，值保存在本地密码管理器（KeePassXC）里；文件里只写"去哪个条目取"
- `状态.md`、`决策记录\`、`文档\` 里带私人信息的部分在**私有仓**，不在这个公开仓
- 所有内容都是个人实践的记录，不保证适用于别的机器

## 三条最容易踩的

- **装环境顺序不能反**：先 Clash Verge 能上网，再装其余（很多包在 GitHub 上）
- **软件装到哪不由清单决定**，看 `安装规划.md`；数据、库、缓存一律 D 盘
- **密钥、令牌、账号密码不进任何仓库**，值放 KeePassXC（`D:\Documents\密码.kdbx`）
