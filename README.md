# 主管理（D:\AI）

这里管理本机公共配置、维护规则和跨项目资料；具体项目放在 `D:\Projects\<名字>`。

> **这是公开部分。** `状态.md`、`决策记录\`、`任务\`、`进行中\`、`收件箱\`、`产物\`、
> `文档\重装清单.md`（含密钥）属于私有部分，`.gitignore` 用白名单把它们排除在外，不在此仓库。
> 下面的目录清单里提到它们，是为了说明完整结构，不代表它们在这里。

新会话从本目录开始时，先读：

1. `AGENTS.md`：工作规则与权限边界
2. `任务清单.md`：由 `任务\` 自动生成的待办总览
3. `状态.md`：本机当前状态

主要目录：

- `任务\`：一个任务一个文件，是待办事实源
- `进行中\`：按任务 ID 创建的原子认领卡
- `决策记录\`：为什么这样定，只追加
- `知识库\`：验证过的做法与排查经验
- `文档\`：长期给人看的说明
- `脚本\`：脚本源码；一次性脚本归入 `脚本\archive\`
- `工具\`：可直接双击的入口
- `产物\`：生成结果与日志
- `收件箱\`：暂时无法归类的内容

运行 `工具\体检.cmd` 可做只读检查；没有 Git 仓库也能使用。
