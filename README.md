# 主管理（D:\AI）

这台电脑的公共部分：装机与维护规则、现状、经验教训。具体项目放 `D:\Projects\<名字>`。

## 我要做什么 → 读哪个

**这张表就是入口。**找不到东西时先回到这里。

| 我要…… | 读这个 |
|---|---|
| 知道今天还有什么要办 | `任务.md` |
| 知道这台电脑现在什么样 | `状态.md` |
| **换电脑 / 重装 / 给新机器打环境** | `文档\软件与模块.md`（装什么）→ `安装规划.md`（装到哪）→ 装完记进 `状态.md` |
| 恢复密钥、订阅、装机后的收尾 | `文档\凭据恢复.md`（**私有**，不进公开仓） |
| 某个软件装在哪、数据放哪 | `安装规划.md` |
| 某件事怎么做、某个坑怎么躲 | `知识库\`（索引：`知识库\README.md`） |
| 为什么当初这么定 | `决策记录\`（索引：`决策记录.md`） |
| 有哪些项目、在哪 | `项目登记表.md` |
| 有什么能直接双击跑 | `工具\工具箱.md` |
| 给人看的说明文档 | `文档\`（索引：`文档\README.md`） |
| **会话开工的规则与红线** | `AGENTS.md` |

新会话从本目录开始时：读 `AGENTS.md` → `任务.md` → `状态.md`，然后动手。

## 三条最容易踩的

- **装环境顺序不能反**：先 Clash Verge 能上网，再装其余（很多包在 GitHub 上）
- **软件装到哪不由清单决定**，看 `安装规划.md`；数据、库、缓存一律 D 盘
- **密钥、令牌、账号密码不进任何仓库**，值放 KeePassXC（`D:\Documents\密码.kdbx`）
