# 知识库索引

经验教训、「怎么做」的东西都在这儿，**一个主题一个文件**。
跟 `决策记录\` 的区别：那边是"为什么这么定"（只追加、不许改），这边是"怎么做"（**可以改写、合并、改错**）。

| 主题 | 什么时候翻它 |
|---|---|
| `Windows-账户与权限.md` | 搞不清命令跑在哪个身份下、读 HKCU 读不到东西、要不要 UAC |
| `Windows-文件与磁盘.md` | 文件删不掉/改不了名、要删一堆小文件、权限与所有权问题 |
| `PowerShell.md` | 写脚本、中文乱码、`sc.exe` 不听话、提权跑脚本 |
| `软件安装与卸载.md` | 装软件、找静默参数、卸载残留清不干净 |
| `Docker.md` | Docker 起不来、要搬数据目录、启停 |
| `网络与代理.md` | 代理配置、端口暴露判断、网络"看起来有问题"的排查 |
| `开机与服务.md` | 开机慢、服务要不要关、自启动项 |
| `硬件与磁盘健康.md` | 看硬盘寿命、判断内存够不够、升级硬件 |

新踩的坑先写进对应主题；没有合适主题就新建一个，然后回来在表格里加一行。
