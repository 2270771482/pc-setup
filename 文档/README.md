# 文档索引

`文档\` 放**给人看的**说明；给会话看的规则在 `AGENTS.md`，踩坑经验在 `知识库\`。

## 现行的

| 文件 | 是什么 | 什么时候用 |
|---|---|---|
| `重装清单.md` | **换电脑的核心文件**：装什么、从哪下载、密钥与订阅怎么恢复（只写密码库条目名，不写值） | 重装 / 换机 / 新机器打环境 |
| `备忘录-加内存分析.md` | 加内存的选型分析（**已完成**：2026-09-19 装了 2×16GB 金泰克 DDR4-3200） | 想复盘为什么这么选时 |

配套的两个文件不在这个目录，但在同一条链上：

- `安装规划.md`（根目录）：**装到哪**、数据目录放哪
- `状态.md`（根目录）：**现在是什么样**

顺序关系：`重装清单.md` 说装什么 → `安装规划.md` 说装到哪 → 装完记进 `状态.md`。
