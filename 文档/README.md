# 文档索引

`文档\` 放**给人看的**说明。给会话看的规则在 `AGENTS.md`，踩坑经验在 `知识库\`，
「为什么这么定」在 `决策记录\`。**总入口是根目录的 `README.md`。**

## 文件

| 文件 | 是什么 | 公开？ | 什么时候用 |
|---|---|---|---|
| `软件与模块.md` | **核心**：装什么、按什么顺序、每个模块的可粘贴命令、怎么验证、出厂预装怎么扫 | 公开 | 换电脑 / 重装 / 给新机器打环境 |
| `凭据恢复.md` | 密钥与订阅怎么恢复（**只写密码库条目名，不写值**）+ 装机后的收尾清单 | **私有** | 装完软件之后 |

## 装环境的这条链

```
文档\软件与模块.md   （装什么、按什么顺序）
      ↓
安装规划.md          （装到哪、数据放哪）
      ↓
文档\凭据恢复.md     （密钥、订阅、装机后的收尾）
      ↓
状态.md              （装完记一行，成为新的"现状"）
```

## 不放在这里的

- 个人文件（文章、资料、图片）→ `D:\Documents`
- 项目自己的文档 → `D:\Projects\<项目>\`
- 备份 → `D:\Backups`
