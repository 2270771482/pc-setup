# 备忘录：配置分析 —— 要不要加内存

创建：2026-09-18　　状态：**待用户决定**（尚未动手）

## 结论先说

- 16GB 已经是实打实的瓶颈（证据见下），**值得加**
- 但两个插槽都占满了，所以动作是「**换两条**」而不是「加一条」
- **已定方案 A：换成 2×16GB = 32GB**（2026-09-18 用户定）
- 不选 64GB 的理由：用户目标是把这台机器**撑两年**、等 RTX 60 系整机换新；
  32GB 已足够消掉现存隐患，多出来的容量在这个用法下吃不到，差价留给新机更值

## 内存为什么是瓶颈（证据）

- 物理内存 15.7GB，**当前可用只剩 1.1GB**，已用 14.7GB
- **提交内存 26.2GB，占提交上限的 91%**：实际需求已超过物理内存六成，
  系统靠页面文件（C 盘 11GB）和内存压缩在硬撑
- 开机 12 小时期间一直是这个状态，不是瞬时峰值
- 当前占用大户：Docker 后端 3.9GB、系统服务合计 1.5GB、Codex 1.2GB、Steam 界面 0.9GB、
  QQ 0.8GB、WeGame 下载器 0.8GB、浏览器合计 1.0GB+、Defender 0.6GB
- 玩 3A 游戏时（游戏本体 + Steam + 后台常驻）只会更紧，卡顿掉帧常常就是内存不够

**2026-09-18 16:58 复测（当时没开 Docker、没开游戏）**：已用 11.5GB / 可用 4.3GB，
**提交 17.4GB，而提交上限只有 18.6GB（= 物理 15.7GB + 系统自动管理的页面文件约 3GB，会伸缩）**，
余量不到 1.2GB；另有 **1.2GB 正被"内存压缩"顶住**（Windows 把内存压缩换空间，代价是 CPU 与切窗口卡顿）。
也就是说：现在是轻载状态，余量已经这么薄；**再开一个大程序就不是变慢，而是直接报"内存不足"退出**。

### 两个插槽都占满了

- 插槽数 **2**，DIMM A / DIMM B 各插一条 8GB，都已占满
- 固件报告最大 128GB；**Dell 官方规格只到 32GB**（2×16GB，规格书明写 per-slot 4/8/16GB，
  金士顿配置器也照抄这个上限）；**Intel i7-11800H 本身支持 128GB**（ARK）——所以 32GB 是 OEM 限制，不是 CPU 限制
- **64GB（2×32GB）实测可用，有据**（2026-09-18 联网核实）：Dell 论坛有用户用英睿达 2×32GB 套装确认识别 64GB；
  另一帖确认 G15 5511 用 1.2V／非 XMP／CL22 的条能认满 64GB（G.Skill F4-3200C22S-32GRS 有成功案例）；
  英睿达自家兼容工具对 G15 5511 也直接给 64GB（2×32GB）套装。**属于"官方不背书但能跑"**
- 因此「加内存」的实际动作是：**拆下两条 8GB，换上两条 16GB**

## 三个方案

| 方案 | 容量 | 说明 |
|---|---|---|
| **A（推荐）** | 2×16GB = 32GB | 官方支持范围内，一次到位；换下的两条 8GB 可留作备用或出二手 |
| B（省钱） | 1×16GB + 原 1×8GB = 24GB | 变成非对称双通道（Intel Flex 模式），性能略降，而且 24GB 以后可能又不够 |
| C（一步到位） | 2×32GB = 64GB | 超出官方规格（固件支持，多数人实测可用），只有重度 Docker／虚拟机才划算，游戏没有额外收益 |

## 买什么（照这个挑）

- 类型：**DDR4 SO-DIMM（260 针笔记本内存）**
- 频率：**3200MHz**（PC4-25600），1.2V
- 单条容量：16GB；方案 A 买两条，**尽量同品牌同型号**
- 时序：标准 CL22 即可。笔记本一般不吃 XMP，买高时序的条也只跑标准频率，白花钱
- 品牌：三星原厂（与现状一致，最省心）、海力士、英睿达、金士顿、威刚、光威都可以
- 价格：以你在京东／拼多多看到的为准（这里不写数字，免得过期）

64GB 的额外注意：超出 Dell 官方规格，**从支持七天无理由的店买**（万一不认好退）；
必须**成对同型号**、JEDEC 1.2V／非 XMP／CL22，装完当天验证识别 64GB 且跑在 3200 双通道。

**详情页必须同时满足**（用这几个词在页面里核对）：
`DDR4` · `SO-DIMM` · `260-pin` · `PC4-25600 / 3200MHz` · `1.2V` · `CL22` · `非 ECC` · `无缓冲`

**不要买**：

- DDR5（物理插不进去）；DDR4 2666／2400（会降频）
- UDIMM / DIMM（那是台式机条，笔记本用的是 SO-DIMM）
- ECC、带"游戏马甲"散热的条（G15 后盖空间紧，且笔记本不吃 XMP，纯白花钱）
- 2×32GB（=64GB）：固件报告支持 128GB，但 Dell 官方只到 32GB，除非重度 Docker／虚拟机否则不划算
