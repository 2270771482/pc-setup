# 软件与模块（换电脑时照着做）

**这份文件决定「装什么、按什么顺序、怎么验证」。**

- 「装到哪、数据放哪」→ `D:\AI\安装规划.md`
- 「密钥与订阅怎么恢复」→ 私有仓里的 `文档\凭据恢复.md`（**密钥值只在 KeePassXC，不在任何文件里**）
- 文档索引 → `文档\README.md`

## 一句话流程

**M1 网络（先能上网）→ M0 基线 → 按模块装 → M9 驱动最后（可能要重启）**，
每装完一个就在 `状态.md` 记一行。

## 两种用法

- **自己的电脑**：M0~M7 基本都装
- **公司 / 别人的电脑**：M1 + M2（微信必装，其余看公司）+ M3；**要做开发才加 M4**；
  M5 按需；**M8 一律不装**（游戏、个人网盘、加速器）

### 给 AI 的三条硬规矩

1. **开工先问清楚「这台是谁的」**（自己 / 公司），再照下表选模块
2. **M5（数据库与容器）装之前必须问用户**——里面是 MySQL / PostgreSQL / Docker，重且未必需要
3. 新机器上先跑一遍「出厂预装扫描」，把可疑项**列给用户判断**，不要自己决定删

## 每个模块的命令

可以整段粘，也可以只挑其中几行。**行尾的包 ID 都在这台机器上核对过。**

### M1 网络（第一步，先做）

winget 源里没有 Clash Verge，用官网或国内加速镜像下安装包：

```text
国内加速：https://ghproxy.net/https://github.com/clash-verge-rev/clash-verge-rev/releases
备用  ：https://ghfast.top/https://github.com/clash-verge-rev/clash-verge-rev/releases
```

装完导入订阅（地址在密码库，见 `凭据恢复.md`）→ 开系统代理（本机是 `127.0.0.1:7897`）。
**后面所有要从 GitHub 拉包的安装（PowerShell 7、Obsidian、Docker…）都得等这步做完。**

### M0 基线

```powershell
winget install --id Microsoft.PowerShell --exact -e
```

装完把 Windows Terminal 默认配置档改成「PowerShell 7」（设置 → 启动 → 默认终端配置文件）。

### M2 通信

```powershell
winget install --id Tencent.WeChat.Universal --exact -e   # 微信（不管什么环境都装）
winget install --id Tencent.QQ.NT --exact -e              # QQ（自己的机器装，公司看情况）
winget install --id Alibaba.DingTalk.Mainland --exact -e  # 钉钉（看公司环境）
winget install --id ByteDance.Feishu --exact -e           # 飞书（看公司环境）
```

### M3 办公

```powershell
winget install --id Kingsoft.WPSOffice.CN --exact -e      # WPS（本机办公套件只用它）
winget install --id NetEase.MailMaster --exact -e         # 网易邮箱大师
winget install --id Tencent.TencentMeeting --exact -e     # 腾讯会议
```

装完确认 `.docx/.xlsx/.pptx` 的默认打开方式是 WPS（WPS 一般会自己接管）。

### M4 开发基础

```powershell
winget install --id Git.Git --exact -e
winget install --id OpenJS.NodeJS.LTS --exact -e
winget install --id Python.Python.3.12 --exact -e
winget install --id JetBrains.IntelliJIDEA.Community --exact -e
winget install --id DBeaver.DBeaver.Community --exact -e
winget install --id Microsoft.WSL --exact -e
```

### M5 数据库与容器（**装之前先问用户**）

```powershell
winget install --id Oracle.MySQL --exact -e

winget install --id Docker.DockerDesktop --exact -e
```

数据库装完**改成手动启动**（平时不跑、不开端口）：`脚本\set-databases-manual.ps1`。

### M6 AI 工具

```powershell
# Codex 走微软商店（国内直连可用）：商店搜 Codex，或让 AI 用 msstore 源装

```

密钥恢复见私有仓的 `文档\凭据恢复.md`。

### M7 安全与凭据

```powershell
winget install --id KeePassXCTeam.KeePassXC --exact -e
```

密码库本身在 D 盘（`D:\Documents\密码.kdbx`），自己的机器重装后不用重建。

### M8 游戏与个人网盘（**公司电脑一律不装**）

```powershell
winget install --id Valve.Steam --exact -e          # Steam（库目录指向 D:\Games\Steam）
winget install --id Baidu.BaiduNetdisk --exact -e   # 百度网盘（下载目录指向 D:\Downloads）
# WeGame 走微软商店：winget install --id XP8LZ3XFW0JQLZ -e --source msstore
```

**雷神加速器（游戏加速，winget 里没有，要下安装器）**

- 官网下载页：`https://www.leigod.com/download/`
- 标准版安装包的真实地址形如
  `https://update.leigod.com/soft/leigod/win/<版本目录>/LeiGodSetup.<版本>.exe`
  （本机 2026-09-19 下的是 `.../win/11.0.0.0/LeiGodSetup.11.3.2.8.exe`，137.5 MB）
- **只下这个标准版**：同目录下还有 `channel/` 里的 `LeiGodSetup_360.exe`、`LeiGodSetup_bd1~bd9.exe`、`_abu` 等
  **渠道推广包**，那些带捆绑，别碰
- **验签名**：正常应显示签名者 `雷神（武汉）网络技术有限公司`、颁发者 DigiCert（EV 代码签名）
- 三个坑：① 它会装**虚拟网卡/网络驱动**（"路由模式"要用），装的时候要管理员；
  ② **默认开机自启**，装完去「系统设置 → 常规设置 → 启动设置」关掉；
  ③ **可能和 Clash Verge 抢路由**——出现"游戏能连但浏览器上不了网"（或反过来）就是两者打架

### M9 驱动与固件（最后做）

不写死：**按每台机器自己看**。本机（Dell G15 5511）是先用 Windows 更新把 Intel 网卡/芯片组/Realtek 声卡装好，
再去 NVIDIA 官网补一次显卡驱动，装完统一重启。

## 装完怎么验证

```powershell
winget list                      # 装的都在不在
$PSVersionTable.PSVersion        # 新终端里应是 7.x（说明 M0 生效）
Get-Service MySQL84, postgresql* # 数据库应是 Stopped + Manual
nvidia-smi                       # 显卡驱动版本（NVIDIA 卡）
```

每装完一个模块，**在 `状态.md` 里记一行**（装了什么、版本、数据目录在哪）。

## 新机器上的「出厂预装扫描」

品牌机（尤其是恢复出厂镜像之后）会带一堆预装软件。**列给用户判断，不要自己删。**

```powershell
# 1) 看安装目录的创建时间是不是等于出厂日期（本机是 2021-07-11）
Get-ChildItem 'C:\Program Files','C:\Program Files (x86)' -Directory |
  Select-Object FullName, CreationTime | Sort-Object CreationTime | Select-Object -First 25

# 2) 看已装软件清单（含 Store 应用）
winget list
Get-AppxPackage | Select-Object Name, Version
```

判据：**目录创建时间 = 出厂日期**、厂商是 Dell/Alienware/McAfee/Intel 之类、名字里带
Support/Assist/Delivery/Analytics、装了却没有开始菜单入口。实例：本机的 **爱奇艺**（1655 个文件全是出厂日期）
就是这么查出来的；同一批里的 **AWCC**（风扇与性能档控制）则必须留。

## 坑

- **重装时（"重置此电脑"）务必选「仅限安装了 Windows 的驱动器」**，否则 D 盘数据和 `D:\AI` 一起没
- **顺序不能反**：没代理之前从 GitHub 拉的包会失败（`InternetOpenUrl() failed 0x80072efd`）
- Codex 是**商店应用**，没有 winget ID，要用 msstore 源或商店搜索
- Clash Verge 也没有 winget 包，得下安装器
- 想省事的话，`脚本\` 里的 `install-all.ps1` 是当初一次性装机用的骨架，可参考但别照抄（里面的版本和路径会过期）
